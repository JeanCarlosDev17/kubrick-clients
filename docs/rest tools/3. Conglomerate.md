# Conglomerate

Este endpoint permite consultar los conglomerados disponibles en PlacetoPay, filtrando por id, name o brand; la información se devuelve paginada.

**Endpoint:** `POST /api/rest-tools/conglomerate/search`

## Filtros

| Field Name | Required | Description | Example |
| ---------- | -------- | ----------- | ------- |
| id | NO | Identificador del conglomerado a buscar. | 1 |
| name | NO | Nombre del conglomerado a buscar. | EGM CO |
| brand | NO | Marca del conglomerado a buscar. | EGM |
| pagination | NO | Objeto de paginación. | {"perPage": 15, "currentPage": 1} |

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `conglomerates`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador del conglomerado. | 1 |
| name | Nombre del conglomerado. | EGM CO |
| brand | Marca del conglomerado. | EGM |

## Ejemplo

**Petición:**

```json
{
    "id": 1,
    "name": "EGM CO",
    "brand": "EGM",
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```

**Respuesta:**

```json
{
    "status": {
        "status": "OK",
        "reason": "RC",
        "message": "The request has been processed successfully",
        "date": "2026-07-15T10:00:00+00:00"
    },
    "conglomerates": [
        {
            "id": 1,
            "name": "EGM CO",
            "brand": "EGM"
        },
        {
            "id": 2,
            "name": "EGM PR",
            "brand": "EGM"
        }
    ],
    "pagination": {
        "total": 2,
        "perPage": 15,
        "currentPage": 1,
        "lastPage": 1
    }
}
```
