# Reseller

Este endpoint permite consultar los resellers disponibles en PlacetoPay; la información se devuelve paginada. Este endpoint no dispone de filtros.

**Endpoint:** `POST /api/rest-tools/reseller/search`

## Filtros

Este endpoint no dispone de filtros, únicamente recibe el objeto `pagination`.

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `resellers`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador del reseller. | 1 |
| name | Nombre del reseller. | PLACETOPAY |
| conditions | Condiciones asociadas al reseller. | null |
| enabled | Indica si el reseller se encuentra habilitado. | true |

## Ejemplo

**Petición:**

```json
{
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```

```json
{
    "status": {
        "status": "OK",
        "reason": "RC",
        "message": "The request has been processed successfully",
        "date": "2026-07-15T10:00:00+00:00"
    },
    "resellers": [
        {
            "id": 1,
            "name": "PLACETOPAY",
            "conditions": null,
            "enabled": true
        },
        {
            "id": 2,
            "name": "EGM INGENIERIA",
            "conditions": null,
            "enabled": true
        }
    ],
    "pagination": {
        "total": 2,
        "perPage": 15,
        "currentPage": 1,
        "lastPage": 1
    }
}
```
