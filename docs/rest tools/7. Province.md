# Province

Este endpoint permite consultar las provincias disponibles en PlacetoPay, filtrando por el código del país (country); la información se devuelve paginada.

**Endpoint:** `POST /api/rest-tools/province/search`

## Filtros

| Field Name | Required | Description | Example |
| ---------- | -------- | ----------- | ------- |
| country | NO | Código ISO 3166-1 alfa-2 del país cuyas provincias se desean consultar (2 caracteres). | CO |
| pagination | NO | Objeto de paginación. | {"perPage": 15, "currentPage": 1} |

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `provinces`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador de la provincia. | 1 |
| name | Nombre de la provincia. | Antioquia |
| short | Nombre corto de la provincia. | ANT |
| iso3166 | Código ISO 3166-2 de la provincia. | ANT |
| country | Código ISO 3166-1 alfa-2 del país al que pertenece la provincia. | CO |
| alias | Alias o código local de la provincia. | 05 |

## Ejemplo

**Petición:**

```json
{
    "country": "CO",
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```

```json
{
    "status": {
        "status": "OK",
        "reason": "RC",

    "provinces": [
        {
            "id": 1,
            "name": "Antioquia",
            "short": "ANT",
            "iso3166": "ANT",
            "country": "CO",
            "alias": "05"
        },
        {
            "id": 2,
            "name": "Cundinamarca",
            "short": "CUN",

        }

        "total": 2,

    }
}
```
