# Airline

Este endpoint permite consultar las aerolíneas disponibles en PlacetoPay, filtrando por id o name; la información se devuelve paginada.

**Endpoint:** `POST /api/rest-tools/airline/search`

## Filtros

| Field Name | Required | Description | Example |
| ---------- | -------- | ----------- | ------- |
| id | NO | Identificador de la aerolínea a buscar. | 1 |
| name | NO | Nombre de la aerolínea a buscar. | AIR CANADA Nacional |
| pagination | NO | Objeto de paginación. | {"perPage": 15, "currentPage": 1} |

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `airlines`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador de la aerolínea. | 1 |
| name | Nombre de la aerolínea. | AIR CANADA Nacional |

## Ejemplo

**Petición:**

```json
{
    "id": 1,
    "name": "AIR CANADA Nacional",
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```

**Respuesta:**

```json
{
    "status": {
        "status": "OK",
        "reason": "RC",
        "message": "The request has been processed successfully",
        "date": "2026-07-15T10:00:00+00:00"
    },
    "airlines": [
        {
            "id": 1,
            "name": "AIR CANADA Nacional"
        },
        {
            "id": 2,
            "name": "AVIANCA Nacional"
        }
    ],
    "pagination": {
        "total": 2,
        "perPage": 15,
        "currentPage": 1,
        "lastPage": 1
    }
}
```
