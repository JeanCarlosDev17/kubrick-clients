# Financial Entity

Este endpoint permite consultar las entidades financieras disponibles en PlacetoPay; la información se devuelve paginada. Este endpoint no dispone de filtros.

**Endpoint:** `POST /api/rest-tools/financial-entity/search`

## Filtros

Este endpoint no dispone de filtros, únicamente recibe el objeto `pagination`.

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `financialEntities`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador de la entidad financiera. | 1 |
| name | Nombre de la entidad financiera. | BANCOLOMBIA |
| disabled | Indica si la entidad financiera se encuentra deshabilitada. | false |

## Ejemplo

**Petición:**

```json
{
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```

**Respuesta:**

```json
{
    "status": {
        "status": "OK",
        "reason": "RC",
        "message": "The request has been processed successfully",
        "date": "2026-07-15T10:00:00+00:00"
    },
    "financialEntities": [
        {
            "id": 1,
            "name": "BANCOLOMBIA",
            "disabled": false
        },
        {
            "id": 2,
            "name": "BANCO DE BOGOTA",
            "disabled": false
        }
    ],
    "pagination": {
        "total": 2,
        "perPage": 15,
        "currentPage": 1,
        "lastPage": 1
    }
}
```
