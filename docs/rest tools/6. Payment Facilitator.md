# Payment Facilitator

Este endpoint permite consultar los facilitadores de pago disponibles en PlacetoPay, filtrando por id, name o active; la información se devuelve paginada.

**Endpoint:** `POST /api/rest-tools/payment-facilitator/search`

## Filtros

| Field Name | Required | Description | Example |
| ---------- | -------- | ----------- | ------- |
| id | NO | Identificador del facilitador de pago a buscar. | 1 |
| name | NO | Nombre del facilitador de pago a buscar. | Keeling-Bernier |
| active | NO | Indica si el facilitador de pago se encuentra activo o inactivo. | true |
| pagination | NO | Objeto de paginación. | {"perPage": 15, "currentPage": 1} |

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `paymentFacilitators`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador del facilitador de pago. | 1 |
| name | Nombre del facilitador de pago. | Keeling-Bernier |
| active | Indica si el facilitador de pago se encuentra activo. | true |
| country | Código ISO 3166-1 alfa-2 del país del facilitador de pago. | CL |
| visa | Identificador del facilitador de pago ante Visa. | 1973076210 |
| mastercard | Identificador del facilitador de pago ante Mastercard. | 963389732 |

## Ejemplo

**Petición:**

```json
{
    "id": 1,
    "name": "Keeling-Bernier",
    "active": true,
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```
