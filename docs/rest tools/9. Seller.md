# Seller

Este endpoint permite consultar los sellers disponibles en PlacetoPay; la información se devuelve paginada. Este endpoint no dispone de filtros.

**Endpoint:** `POST /api/rest-tools/seller/search`

## Filtros

Este endpoint no dispone de filtros, únicamente recibe el objeto `pagination`.

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `sellers`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador del seller. | 1 |
| name | Nombre del seller. | John Doe |
| alias | Alias del seller. | EGM |
| disabled | Indica si el seller se encuentra deshabilitado. | false |

## Ejemplo

**Petición:**

```json
{
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```

**Respuesta:**

```json
{
    "status": {
        "status": "OK",
        "reason": "RC",
        "message": "The request has been processed successfully",
        "date": "2026-07-15T10:00:00+00:00"
    },
    "sellers": [
        {
            "id": 1,
            "name": "John Doe",
            "alias": "EGM",
            "disabled": false
        },
        {
            "id": 2,
            "name": "Jane Doe",
            "alias": "PTP",
            "disabled": false
        }
    ],
    "pagination": {
        "total": 2,
        "perPage": 15,
        "currentPage": 1,
        "lastPage": 1
    }
}
```
