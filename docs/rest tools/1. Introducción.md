# Rest Tools

Las Rest Tools son un conjunto de endpoints de consulta que permiten obtener los identificadores de referencia utilizados por PlacetoPay (aerolíneas, conglomerados, entidades financieras, grupos, facilitadores de pago, provincias, resellers y sellers). Estos identificadores son útiles al momento de construir las peticiones de creación o actualización de recursos.

Todos los endpoints comparten el mismo comportamiento:

* Se consumen por medio de una petición `POST` autenticada con el token Bearer del usuario.
* La información se devuelve paginada.
* En caso de no encontrar coincidencias, el array de resultados se devuelve vacío con una respuesta `200`.

## Paginación

Todos los endpoints reciben un objeto `pagination` opcional en la petición:

| Field Name | Required | Description | Example |
| ---------- | -------- | ----------- | ------- |
| perPage | YES* | Indica cuantos registros mostrar en la respuesta. | 15 |
| currentPage | YES* | Indica la página que queremos recibir en la respuesta. | 1 |

\* Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`). Si se envía, ambos campos son requeridos.

La respuesta incluye siempre el objeto `pagination` con la siguiente estructura:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| total | Cantidad total de registros disponibles. | 30 |
| perPage | Cantidad de registros por página. | 15 |
| currentPage | Página actual. | 1 |
| lastPage | Última página disponible. | 2 |

## Respuestas y códigos de error

| Código HTTP | Reason | Descripción |
| ----------- | ------ | ----------- |
| 200 | RC | La petición se procesó correctamente. |
| 400 | BR | Error de validación en los datos enviados o petición rechazada por el servicio externo. |
| 401 | FA | Fallo de autenticación, verifique el token. |
| 500 | Ver tabla por tool | Error interno o error del servicio externo. |

Cada tool tiene su propio reason code para los errores internos (500):

| Tool | Reason |
| ---- | ------ |
| Airline | ASE |
| Conglomerate | CSE |
| Financial Entity | FESE |
| Group | GSE |
| Payment Facilitator | PFSE |
| Province | PSE |
| Reseller | RSE |
| Seller | SSE |
