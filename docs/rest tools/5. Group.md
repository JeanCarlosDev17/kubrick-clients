# Group

Este endpoint permite consultar los grupos de usuario disponibles en PlacetoPay, filtrando por id o code; la información se devuelve paginada.

**Endpoint:** `POST /api/rest-tools/group/search`

## Filtros

| Field Name | Required | Description | Example |
| ---------- | -------- | ----------- | ------- |
| id | NO | Identificador del grupo a buscar. | 1 |
| code | NO | Código del grupo a buscar. | GROUP_ROOT |
| pagination | NO | Objeto de paginación. | {"perPage": 15, "currentPage": 1} |

Si no se envía el objeto `pagination`, se aplica la paginación por defecto (`perPage: 15`, `currentPage: 1`); si se envía, los campos `perPage` y `currentPage` son requeridos.

## Campos de la respuesta

Los resultados se devuelven en el array `groups`:

| Field Name | Description | Example |
| ---------- | ----------- | ------- |
| id | Identificador del grupo. | 1 |
| code | Código del grupo. | GROUP_ROOT |
| name | Nombre del grupo. | Superusuario |
| description | Descripción del grupo. | Usuario con todos los privilegios sobre la aplicación, incluyendo seguridad. |

## Ejemplo

**Petición:**

```json
{
    "id": 1,
    "code": "GROUP_ROOT",
    "pagination": {
        "perPage": 15,
        "currentPage": 1
    }
}
```

**Respuesta:**

```json
{
    "status": {
        "status": "OK",
        "reason": "RC",
        "message": "The request has been processed successfully",
        "date": "2026-07-15T10:00:00+00:00"
    },
    "groups": [
        {
            "id": 1,
            "code": "GROUP_ROOT",
            "name": "Superusuario",
            "description": "Usuario con todos los privilegios sobre la aplicación, incluyendo seguridad."
        },
        {
            "id": 2,

            "description": "Usuario con privilegios administrativos sobre la aplicación."
        }

        "currentPage": 1,

    }
}
```
