# Integraciones del sitio

Las integraciones permiten habilitar un servicio externo en el sitio de recaudo, configurando los datos requeridos para su correcto funcionamiento.

A continuación, se muestran las integraciones externas disponibles hasta el momento:

| Nombre de la Integración | Código             |
| ------------------------ | ------------------ |
| PAYGATE                  | paygate            |
| INVOICE_SETTLE           | invoice_settle     |
| KOUNT                    | kount              |
| ACCOUNT_VALIDATOR        | account_validator  |
| PUSH_NOTIFICATION        | push_notification  |
| BRAND_TOKENIZATION       | brand_tokenization |
| NOTIFIER                 | notifier           |
| CLICK_TO_PAY             | clicktopay         |
| AZURE_NOTIFICATION       | azure_notification |
| OPEN_FINANCE             | open_finance       |

Las integraciones se envian dentro del objeto de [Site](https://kubrick.stoplight.io/docs/kubrick-clients/boc3j3wz5bfku-site) al momento de realizar una petición de [crear integración](https://kubrick.stoplight.io/docs/kubrick-clients/sa1wbtq1n5cz4-create). Cada sitio puede contar con multiples integraciones, estas se envían dentro del array "externalIntegrations", tal como se muestra en el siguiente ejemplo:

```json
{
  "statusWebhook": "...",
  "merchant": "...",
  "site": {
    "name": "...",
    "displayName": "...",
    "externalIntegrations": [
      {
        "type": "kount",
        "settings": {
          "sandbox": false,
          "website": "prohaska.com",
          "merchant": "Cummerata Group",
          "apiKey": "0b64d99c-8a71-3434-ae96-5e08f3a89805"
        }
      },
      {
        "type": "notifier",
        "settings": {
          "handler": "est",
          "retry_until": 27926,
          "retry_after": 543,
          "enabled": true,
          "additional": {
            "uri": "http://bartell.info/aut-illum-laudantium-impedit-omnis-sit"
          }
        }
      },
      {
        "type": "clicktopay",
        "settings": {
          "id": "f064d613-2b3d-3f65-94fe-7bb4fefc8098",
          "register_default": false,
          "instrument_type": "ipsam"
        }
      }
    ]
  },
  "threeDS": "...",
  "paymentMethods": "..."
}
```

Por último, en la parte inferior, se explicarán cada una de las integraciones con sus reglas respectivas.

## PAYGATE

| Field Name            | Required | Example                              |
| --------------------- | -------- | ------------------------------------ |
| type                  | Yes      | `"paygate"`                          |
| settings.returnUrl    | Yes      | `"https://example.com/return"`       |
| settings.md5Hash      | Yes      | `"d41d8cd98f00b204e9800998ecf8427e"` |
| settings.soapUsername | Yes      | `"my_soap_user"`                     |
| settings.soapPassword | Yes      | `"superSecretPass123!"`              |

Ejemplo:

```json
{
  "type": "paygate",
  "settings": {
    "returnUrl": "https://example.com/return"",
    "md5Hash": "d41d8cd98f00b204e9800998ecf8427e",
    "soapUsername": "my_soap_user",
    "soapPassword": "superSecretPass123"
  }
}
```

## NOTIFIER

| Field Name                          | Required | Example                          |
| ----------------------------------- | -------- | -------------------------------- |
| type                                | Yes      | `"notifier"`                     |
| settings.handler                    | Yes      | `"email"`                        |
| settings.allowedStatuses            | No       | `["APPROVED","REJECTED"]`        |
| settings.allowedStatuses.*          | No       | `"APPROVED"`                     |
| settings.retryUntil                 | Yes      | 300                              |
| settings.retryAfter                 | Yes      | 30                               |
| settings.enabled                    | Yes      | true                             |
| settings.urlForward                 | No       | `"https://example.com/forward"`  |
| settings.additional.uri             | Yes      | `"https://example.com/callback"` |
| settings.additional.user            | No       | `"api_user"`                     |
| settings.additional.password        | No       | `"password123"`                  |
| settings.additional.auth            | No       | `{}`                             |
| settings.additional.headers         | No       | `{}`                             |
| settings.additional.paymentStatus   | No       | `["APPROVED"]`                   |
| settings.additional.paymentStatus.* | No       | `"APPROVED"`                     |
| settings.additional.emails          | No       | `["test@example.com"]`           |

Ejemplo:

```json
{
  "type": "notifier",
  "settings": {
    "handler": "email",
    "allowedStatuses": ["APPROVED", "REJECTED"],
    "retryUntil": 300,
    "retryAfter": 30,
    "enabled": true,
    "urlForward": "https://example.com/forward",
    "additional": {
      "uri": "https://example.com/callback",
      "user": "api_user",
      "password": "password123",
      "auth": {},
      "headers": {},
      "paymentStatus": ["APPROVED"],
      "emails": ["test@example.com"]
    }
  }
}
```
