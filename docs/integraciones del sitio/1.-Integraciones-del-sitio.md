# Integraciones del sitio

Las integraciones permiten habilitar un servicio externo en el sitio de recaudo, configurando los datos requeridos para su correcto funcionamiento.

A continuación, se muestran las integraciones externas disponibles hasta el momento:

| Nombre de la Integración | Código             |
| ------------------------ | ------------------ |
| PAYGATE                  | paygate            |
| INVOICE_SETTLE           | invoice_settle     |
| KOUNT                    | kount              |
| ACCOUNT_VALIDATOR        | account_validator  |
| PUSH_NOTIFICATION        | push_notification  |
| BRAND_TOKENIZATION       | brand_tokenization |
| NOTIFIER                 | notifier           |
| CLICK_TO_PAY             | clicktopay         |
| AZURE_NOTIFICATION       | azure_notification |
| OPEN_FINANCE             | open_finance       |

Las integraciones se envian dentro del objeto de [Site](https://kubrick.stoplight.io/docs/kubrick-clients/boc3j3wz5bfku-site) al momento de realizar una petición de [crear integración](https://kubrick.stoplight.io/docs/kubrick-clients/sa1wbtq1n5cz4-create). Cada sitio puede contar con multiples integraciones, tal como se muestra en el siguiente ejemplo:

```json
{
  "statusWebhook": "...",
  "merchant": "...",
  "site": {
    "name": "...",
    "displayName": "...",
    "externalIntegrations": [
      {
        "type": "kount",
        "settings": {
          "sandbox": false,
          "website": "prohaska.com",
          "merchant": "Cummerata Group",
          "apiKey": "0b64d99c-8a71-3434-ae96-5e08f3a89805"
        }
      },
      {
        "type": "notifier",
        "settings": {
          "handler": "est",
          "retry_until": 27926,
          "retry_after": 543,
          "enabled": true,
          "additional": {
            "uri": "http://bartell.info/aut-illum-laudantium-impedit-omnis-sit"
          }
        }
      },
      {
        "type": "clicktopay",
        "settings": {
          "id": "f064d613-2b3d-3f65-94fe-7bb4fefc8098",
          "register_default": false,
          "instrument_type": "ipsam"
        }
      }
    ]
  },
  "threeDS": "...",
  "paymentMethods": "..."
}
```

Por último, en la parte inferior, se explicarán cada una de las integraciones con sus reglas respectivas.

## PAYGATE

| Field Name            | Required | Description                                                 | Example                              | Observations |
| --------------------- | -------- | ----------------------------------------------------------- | ------------------------------------ | ------------ |
| type                  | Yes      | Identificador del tipo de integración                       | `"paygate"`                       |              |
| settings.returnUrl    | Yes      | URL a la que el usuario será redirigido después del proceso | `"https://example.com/return"`       |              |
| settings.md5Hash      | Yes      | Hash MD5 usado para validación o firma de datos             | `"d41d8cd98f00b204e9800998ecf8427e"` |              |
| settings.soapUsername | Yes      | Usuario del servicio SOAP                                   | `"my_soap_user"`                     |              |
| settings.soapPassword | Yes      | Contraseña del servicio SOAP                                | `"superSecretPass123!"`              |              |


Ejemplo:

```json
{
  "type": "paygate",
  "settings": {
    "returnUrl": "https://example.com/return"",
    "md5Hash": "d41d8cd98f00b204e9800998ecf8427e",
    "soapUsername": "my_soap_user",
    "soapPassword": "superSecretPass123"
  }
}
```

## INVOICE_SETTLE

| Field Name        | Required | Description                           | Example                     | Observations |
| ----------------- | -------- | ------------------------------------- | --------------------------- | ------------ |
| type              | Yes      | Identificador del tipo de integración | `"invoice_settle"`          |              |
| settings.handler  | Yes      | Nombre del handler configurado        | `"handler_name"`            |              |
| settings.url      | Yes      | URL del endpoint del servicio         | `"https://example.com/api"` |              |
| settings.username | Yes      | Usuario para autenticación            | `"my_user"`                 |              |
| settings.password | Yes      | Contraseña para autenticación         | `"my_password"`             |              |

Ejemplo:

```json
{
  "type": "invoice_settle",
  "settings": {
    "handler": "handler_name",
    "url": "https://example.com/api",
    "username": "my_user",
    "password": "my_password"
  }
}
```

## KOUNT

| Field Name        | Required | Description                                | Example           | Observations |
| ----------------- | -------- | ------------------------------------------ | ----------------- | ------------ |
| type              | Yes      | Identificador del tipo de integración      | `"kount"`         |              |
| settings.sandbox  | Yes      | Indica si usa ambiente sandbox             | false             |              |
| settings.website  | Yes      | Identificador del sitio (Kount Website ID) | `"mysite.com"`    |              |
| settings.merchant | Yes      | Merchant ID asignado por Kount             | `"Merchant123"`   |              |
| settings.apiKey   | No       | API Key utilizada para validación          | `"abcd-1234-xyz"` |              |

Ejemplo:

```json
{
  "type": "kount",
  "settings": {
    "sandbox": false,
    "website": "mysite.com",
    "merchant": "Merchant123",
    "apiKey": "abcd-1234-xyz"
  }
}
```

## NOTIFIER

| Field Name                          | Required | Description                                        | Example                          | Observations |
| ----------------------------------- | -------- | -------------------------------------------------- | -------------------------------- | ------------ |
| type                                | Yes      | Identificador del tipo de integración              | `"notifier"`                     |              |
| settings.handler                    | Yes      | Identificador del handler de notificación          | `"email"`                        |              |
| settings.allowedStatuses            | No       | Lista de estados permitidos                        | `["APPROVED", "REJECTED"]`       |              |
| settings.allowedStatuses.*          | No       | Estado permitido individual                        | `"APPROVED"`                     |              |
| settings.retryUntil                 | Yes      | Tiempo máximo para reintentar                      | 300                              |              |
| settings.retryAfter                 | Yes      | Tiempo de espera entre reintentos                  | 30                               |              |
| settings.enabled                    | Yes      | Activa o desactiva la integración                  | true                             |              |
| settings.urlForward                 | No       | URL opcional para reenvío                          | `"https://example.com/forward"`  |              |
| settings.additional.uri             | Yes      | URL base adicional                                 | `"https://example.com/callback"` |              |
| settings.additional.user            | No       | Usuario adicional (requerido por algunos handlers) | `"api_user"`                     |              |
| settings.additional.password        | No       | Contraseña adicional                               | `"password123"`                  |              |
| settings.additional.auth            | No       | Configuración de autenticación avanzada            | `{}`                             |              |
| settings.additional.headers         | No       | Encabezados adicionales                            | `{}`                             |              |
| settings.additional.paymentStatus   | No       | Lista de estados de pago                           | `["APPROVED"]`                   |              |
| settings.additional.paymentStatus.* | No       | Estado de pago individual                          | `"APPROVED"`                     |              |
| settings.additional.emails          | No       | Correos adicionales                                | `["test@example.com"]`           |              |

Ejemplo:

```json
{
  "type": "notifier",
  "settings": {
    "handler": "email",
    "allowedStatuses": ["APPROVED", "REJECTED"],
    "retryUntil": 300,
    "retryAfter": 30,
    "enabled": true,
    "urlForward": "https://example.com/forward",
    "additional": {
      "uri": "https://example.com/callback",
      "user": "api_user",
      "password": "password123",
      "auth": {},
      "headers": {},
      "paymentStatus": ["APPROVED"],
      "emails": ["test@example.com"]
    }
  }
}
```
